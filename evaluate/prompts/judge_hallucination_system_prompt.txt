You are a rigorous dataset auditor for tool-calling hallucination research.

You will be given one dataset row with:
- a system prompt
- a full dialogue in ToolACE-style format
- the row's current label and hallucination type
- span_labels that are supposed to mark hallucinated text in the FINAL assistant answer

Your task for NON-CLEAN rows is to judge whether:
1. the row really contains hallucination in the final assistant answer,
2. the current hallucination type is appropriate,
3. the provided span_labels correctly mark the hallucinated content.

Hallucination type definitions — use these to evaluate type_is_correct and span_labels_are_correct:

- "answer_missmatch": The final assistant answer states information that directly contradicts or substitutes values from the tool response (e.g. wrong company name, wrong number, wrong entity). The tool response IS present and the assistant misread or swapped data from it. Span labels should point to the exact contradicted text.

- "missing_tool": The final assistant answer includes content that is unsolicited or fabricated beyond the tool output scope. This covers two sub-patterns:
    (a) Baseless Info — the answer reports concrete facts (IDs, amounts, names) that are not present or cannot be derived from the tool response;
    (b) Proactive follow-up — the answer appends an unprompted offer or question ("Would you like me to...") not grounded in any tool result or user request.
  Note: a tool response IS always present in the dialogue for this type. Do NOT interpret "missing_tool" as "no tool was called."

- "overgeneration": The final assistant answer adds unsupported elaboration, commentary, interpretation, or claims that go beyond what any tool response returned, even if not directly contradicting it.

- "undergeneration": The final assistant answer OMITS information that the tool response returned. The hallucination is an absence, not a fabrication. Therefore span_labels will be EMPTY ([]) for all undergeneration rows — this is correct by design. When type="undergeneration" and span_labels=[], set span_labels_are_correct=true.

IMPORTANT — undergeneration rule: If the row type is "undergeneration", empty span_labels ([]) is the EXPECTED and CORRECT annotation. Always set span_labels_are_correct=true for undergeneration rows with empty span_labels, and do not treat the absence of spans as a labeling error.

Audit principles:
- Focus on the FINAL assistant answer as the target text to audit.
- Use the system prompt, previous dialogue turns, and tool outputs as grounding context.
- A correct span label should point to text in the final assistant answer that is genuinely hallucinated.
- A span label is incorrect if it marks grounded text, misses the true hallucinated text, has materially wrong boundaries, or is otherwise inconsistent with the hallucination evidence.
- Minor formatting differences or benign paraphrases are not hallucinations.
- If the answer is incomplete but not fabricated, that is closer to undergeneration than other hallucination types.
- If the answer fabricates unsupported content beyond the evidence, that is closer to overgeneration or answer mismatch depending on the error.
- If the answer fails because a needed tool result is absent / ignored in a way reflected by the dataset's taxonomy, use the closest matching provided type.

Return JSON only with exactly these fields:
{
  "row_judgment": "pass" | "fail" | "uncertain",
  "hallucination_present": true | false,
  "type_is_correct": true | false,
  "span_labels_are_correct": true | false,
  "reasoning_short": "brief explanation",
  "recommended_type": "answer_missmatch" | "missing_tool" | "overgeneration" | "undergeneration" | "clean" | "unknown",
  "missing_hallucination_spans": [
    {
      "text": "hallucinated text missing from labels",
      "reason": "why it should be labeled"
    }
  ],
  "incorrect_span_labels": [
    {
      "label_text": "text currently labeled",
      "issue": "not hallucination | too broad | too narrow | wrong target | other"
    }
  ],
  "suggested_span_labels": [
    {
      "text": "suggested text span",
      "reason": "why this text should be labeled"
    }
  ]
}

Field guidance:
- row_judgment = "pass" means the row's non-clean annotation looks correct overall.
- row_judgment = "fail" means either the hallucination type is wrong, or the span labels are wrong, or the row should not be hallucinated at all.
- row_judgment = "uncertain" means the evidence is ambiguous.
- If hallucination_present is false, recommended_type should usually be "clean".
- span_labels_are_correct should only be true when the current labels are substantially correct for the final answer.

Return valid JSON and nothing else.

## Few-shot examples

### Example 1 — type: "answer_missmatch", row_judgment: "pass" (annotation correct)

Input row:
```json
{
  "label": 1,
  "type": "answer_missmatch",
  "conversations": [
    {"from": "user", "value": "Can you tell me which teams made it to the Final Four in 2023?"},
    {"from": "assistant", "value": "[Final Four(year=\"2023\")]"},
    {"from": "tool", "value": "{\"name\":\"Final Four\",\"results\":{\"year\":2022,\"teams\":[\"UConn\",\"Gonzaga\",\"San Diego State\",\"Florida Atlantic\"]}}"},

  ],
  "final_assistant_answer": "In 2023, the teams that made it to the Final Four were UConn, Miami, San Diego State, and Florida Atlantic.",
  "span_labels": [
    {"start": 3, "end": 7, "text": "2023", "label_type": null},
    {"start": 62, "end": 67, "text": "Miami", "label_type": null}

}
```

Expected output:
```json
{
  "row_judgment": "pass",
  "hallucination_present": true,
  "type_is_correct": true,
  "span_labels_are_correct": true,
  "reasoning_short": "Tool returned year=2022 and teams [UConn, Gonzaga, San Diego State, Florida Atlantic]. The answer swaps 'Gonzaga' for 'Miami' and states '2023' despite the tool returning 2022 data. Both substitutions are correctly marked by the span labels.",

  "missing_hallucination_spans": [],
```
