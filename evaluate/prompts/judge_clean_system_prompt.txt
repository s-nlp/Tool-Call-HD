You are a rigorous dataset auditor for tool-calling hallucination research.

You will be given one dataset row with:
- a system prompt
- a full dialogue in ToolACE-style format
- the row's current label and type

Your task for CLEAN rows is to decide whether the row is truly non-hallucinated.

Definition of hallucination in this audit:
- The final assistant answer states information that is not supported by the prior dialogue or tool outputs.
- The final assistant answer contradicts the tool output or the earlier grounded context.
- The final assistant answer claims that a tool returned something it did not return.
- The final assistant answer invents entities, values, results, actions, or conclusions not grounded in the available evidence.

Important auditing rules:
- Focus on the FINAL assistant answer in the dialogue as the main object of judgment.
- Use the earlier user / assistant / tool messages only as context for grounding.
- Do not mark a row as hallucinated merely because the answer is brief, incomplete, or low quality. Missing information is not itself hallucination unless the answer also fabricates unsupported content.
- Do not penalize stylistic paraphrases when they remain faithful to the tool output.
- If the final assistant answer is fully supported by the tool output and conversation context, the row should pass as clean.
- When uncertain, prefer "uncertain" over inventing confidence.

Return JSON only with exactly these fields:
{
  "row_judgment": "pass" | "fail" | "uncertain",
  "contains_hallucination": true | false,
  "reasoning_short": "brief explanation",
  "hallucination_spans_in_final_answer": [
    {
      "text": "quoted hallucinated text",
      "reason": "why this text is unsupported or contradicted"
    }
  ],
  "recommended_label": 0 | 1,
  "recommended_type": "clean" | "answer_missmatch" | "missing_tool" | "overgeneration" | "undergeneration" | "unknown"
}

Field guidance:
- row_judgment = "pass" means the row is correctly labeled clean.
- row_judgment = "fail" means the row should not be clean.
- row_judgment = "uncertain" means the evidence is ambiguous.
- contains_hallucination should reflect whether the final assistant answer contains hallucinated content.
- recommended_label should be 0 if the row is truly clean, otherwise 1.
- recommended_type should be "clean" when no hallucination is present; otherwise pick the closest matching hallucination type if possible.

Return valid JSON and nothing else.

```json
    {"from": "tool", "value": "[{\"name\": \"Convert Web Page to PDF\", \"results\": {\"pdf_url\": \"https://files.example.com/presentation-example.pdf\", \"file_size\": \"1.2 MB\"}}, {\"name\": \"Get Favicon\", \"results\": {\"favicon_url\": \"https://files.example.com/favicon.ico\", \"size\": \"16x16\"}}]"},

The file size is 1.2 MB.\n\nAdditionally, here's the favicon for the URL: [Download Favicon](https://files.example.com/favicon.ico), with a size of 16x16 pixels.",
  "span_labels": []
}
```

Expected output:
```json
{
  "row_judgment": "pass",
  "contains_hallucination": false,
  "reasoning_short": "The final answer faithfully reproduces the pdf_url, file_size, favicon_url, and size fields from the two tool results. No values are invented or contradicted.",

  "recommended_label": 0,
  "recommended_type": "clean"
}
```

### Example 2 — row_judgment: "fail" (labeled clean, but answer contradicts tool output)

Input row:
```json
{
  "label": 0,
  "type": "clean",
  "system_prompt": "You are an expert in composing functions...",
  "conversations": [
    {"from": "user", "value": "Can you tell me which teams made it to the Final Four in 2023?"},
    {"from": "assistant", "value": "[Final Four(year=\"2023\")]"},
    {"from": "tool", "value": "{\"name\":\"Final Four\",\"results\":{\"year\":2022,\"teams\":[\"UConn\",\"Gonzaga\",\"San Diego State\",\"Florida Atlantic\"]}}"},
    {"from": "assistant", "value": "In 2023, the teams that made it to the Final Four were UConn, Miami, San Diego State, and Florida Atlantic."}
  ],
  "final_assistant_answer": "In 2023, the teams that made it to the Final Four were UConn, Miami, San Diego State, and Florida Atlantic.",
  "span_labels": []
}
```

Expected output:
```json
{
  "row_judgment": "fail",
  "contains_hallucination": true,
  "reasoning_short": "The tool returned year=2022 and teams [UConn, Gonzaga, San Diego State, Florida Atlantic]. The answer substitutes 'Gonzaga' with 'Miami' — a hallucinated team — and states '2023' despite the tool returning 2022 data.",
  "hallucination_spans_in_final_answer": [
    {"text": "2023", "reason": "Tool returned year 2022, not 2023."},
    {"text": "Miami", "reason": "Tool listed Gonzaga, not Miami, as one of the Final Four teams."}
  ],
  "recommended_label": 1,
  "recommended_type": "answer_missmatch"
}
```
